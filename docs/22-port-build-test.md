# Port Build & Test (Phase 5)

## Project layout
```
src/main.s            65C02 port source (ca65)
src/supervision.inc   SV hardware register equates (docs/20)
cfg/supervision.cfg   ld65 linker config (SV 32K cart memory map)
Makefile              build -> build/super-mario-land.sv
build/                output (gitignored): main.o, super-mario-land.sv, snap/
```

## Build
```
make                  # ca65 + ld65 -> build/super-mario-land.sv (32K)
```
Output is a raw Supervision cartridge image: `[BANK0 16K][FIXED 16K]`. The fixed bank
maps to `$C000–$FFFF` and holds the 65C02 vectors at `$FFFA` (NMI), `$FFFC` (RESET),
`$FFFE` (IRQ).

## Test (Supervision emulators)
- **RetroArch + Potator core** — drag the `.sv` in. (Confirmed booting.)
- **MAME** (`svision` driver, no BIOS needed) — headless screenshot:
  ```
  mame svision -cart build/super-mario-land.sv \
    -video none -sound none -nothrottle -seconds_to_run 3 \
    -autoboot_script build/snap.lua -autoboot_delay 1 \
    -snapshot_directory build/snap \
    -cfg_directory build/mame -nvram_directory build/mame -homepath build/mame
  # build/snap.lua: snapshot at frame 90 then manager.machine:exit()
  ```
  Snapshot → `build/snap/svision/0000.png`. (The `-*_directory build/mame` flags keep
  MAME's autogenerated config/nvram out of the project tree — it otherwise writes
  `cfg/svision.cfg` etc. into CWD.)

## First slice — status: ✅ VERIFIED (boot + NMI loop + input + video)
`src/main.s` boots the SV (display + NMI + bank via `$2026`, LCD size/scroll), runs an
NMI-driven frame loop, reads `$2020` and remaps to the GB button layout
(`held`/`pressed` ≡ GB `$FF80`/`$FF81`), and fills the full framebuffer (stride `$30`)
with a uniform shade that cycles (`frame_count`) and shifts when buttons are held.
Verified in MAME + Potator: clean full-screen grey, animates, no artifacts.
